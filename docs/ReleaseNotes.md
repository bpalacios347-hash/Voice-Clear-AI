# Release Notes (Version 1.0.0)

**Initial Release of Voice Clear AI**

Features:
- **Real-Time AI Noise Cancellation:** Integrates DeepFilterNet3 for high-quality background noise removal (fans, typing, HVAC, street noise).
- **Virtual Audio Driver:** Appears as a native Windows microphone compatible with Zoom, Teams, Discord, and OBS.
- **Headless Service Architecture:** The core engine runs silently in the background. You do not need to keep the UI open.
- **Ultra-Low Latency:** Hardware-optimized AVX2 processing ensures under 10ms round-trip delay.
