# Installation Guide

1. Download the `VoiceClear_Installer_v1.0.msi`.
2. Run the installer and grant Administrator privileges (Required to install the Virtual Driver and Windows Service).
3. The installer will automatically:
   - Install `VoiceClearService.exe` and start it.
   - Install the virtual audio driver.
   - Install the `VoiceClear.exe` Qt UI.
4. Launch the application from your desktop or start menu.

## Uninstallation
Run the installer again and select "Remove" or use the Windows "Add or Remove Programs" menu. This will cleanly deregister the service and driver.
